# NeMo RL Main Smoke Warning TODO

Audited runs: `1163360`, `1166684`, `1170395`, and `1172030`.

The class-by-class inventory below was refreshed against the complete
`ray-driver.log` from job `1170395`. Counts and run-specific conclusions refer
to that job unless another job is named explicitly.

This list triages every warning observed in the audited smoke runs. The preferred order
for resolving an actionable item is:

1. configuration or launcher correction;
2. update to an upstream revision containing the fix;
3. a narrowly scoped local patch only when neither option is viable.

Warnings marked **Expected / no action** are retained for auditability. They
must not be "fixed" by changing model outputs, hiding failures, or carrying
unnecessary downstream patches.

## Highest-Priority Surgical Fix Candidates

These are the only current candidates for narrow changes, in priority order.
Each should first be attempted through configuration or an upstream update.

1. **Validate CP1 with sequence packing and `attention_backend=auto`.** CP2 has no supported configuration in the current stack; CP1 lets TE use its supported fallback without changing framework code.
2. **Validate prefix-cache invalidation across refit.** Start with prefix caching disabled, then re-enable it only after a supported lifecycle drains requests and confirms a successful reset before serving updated weights.
3. **Make launcher GPU autodetection consume one normalized Slurm GPU count.** This is isolated launcher code and removes dependence on an explicit masking override.
4. **Correct the existing-tensor conversion at its owning call site.** Do this only after a test establishes whether reuse, `as_tensor()`, or `clone().detach()` is semantically correct.

The compiled-DAG timeout is no longer a fix candidate: the launcher-level 1210-second
setting was validated without changing Ray or vLLM.

Everything else should currently be handled by configuration, dependency pin
alignment, an upstream update, monitoring, or explicit acceptance as expected
behavior.
